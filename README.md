# 灵契山海

一个基于 Godot 4 的 2D 修仙题材实时动作 RPG 原型。核心循环是：探索青岚谷、主动指挥灵兽制造灵印、由修士限时追击完成同契破势，并在执念归零的确定性契机中缔结新伙伴。

核心玩家承诺：**你收服的不是一只自动宠物，而是一套新的战斗语法。** 设计冻结与验收边界见 `docs/CORE_GAMEPLAY.md`，主流成功玩法与反证研究见 `docs/GAMEPLAY_RESEARCH.md`。

## 当前可玩内容

- WASD 自由移动，鼠标指向攻击，Space 闪避并获得短暂无敌帧。
- 五种属性灵兽具有巡游、感知、追击、攻击、硬直和强度成长。
- 流云仙鹤会远程施放风刃，紫电狻猊会发射雷丸；精英狻猊拥有“雷狩—雷甲—雷行”三段战势，需要实时走位、闪避并主动换伴。
- 雷甲阶段以赤焰灵狐击穿防护，雷行阶段以碧玉月兔截停追狩；错误伙伴仍能推进但效率更低。击退或结契首领均获得完整五十灵石奖励并持久化结局。
- 新旅程由清虚散人借予碧玉月兔，开场即可体验双身战斗，不必先单人刷怪。
- 整张青岚谷、云游修士、清虚散人和五种灵兽均已换成统一方向的手绘素材；修士与五种灵兽全部拥有四方向、每方向四帧的真实步态、跳跃、飞行、爬行或奔跑动画，并保留攻击前摇、冲刺倾斜、受击闪色与像素轮廓。动作表经过逐格 Alpha 与连通域去噪，玄甲龟另有小尺寸亮度补偿。
- 御灵、同契破势和结契会播放不足 0.6 秒的高清立绘切入，但不暂停实时战斗；对话面板显示导师立绘。
- 鼠标右键向目标下达伙伴主动御灵指令；伙伴不再自动充当炮台。
- 御灵制造短暂灵印，修士必须在窗口内用左键剑诀追击，才能削减目标执念。
- 赤焰灵狐以短窗口换取高破势与爆发；碧玉月兔拥有长窗口、稳定控制与追击回复。
- 玄岩灵龟具有减免普通剑伤的玄甲，焰狐协同可破甲；流云仙鹤会御风拉距，月兔御灵可将其定身。错误伙伴仍可取胜，但会付出更多协同与走位成本。
- Q 向鼠标位置投掷灵契符；执念未破必定失败，契机出现后必定成功，不使用随机抽奖。
- 鼠标指向附近灵兽会显示其实时气血、执念、灵印状态与结契契机。
- R 轮换出战灵兽，Tab 查看灵兽谱。
- 修士经验、突破、灵石、灵兽经验/羁绊和三阶段引导任务。
- 青岚阵持续恢复，死亡后回阵并损失少量灵石。
- 青岚阵旁的清虚散人会依据当前任务阶段提供动态指引，靠近后按 E 交谈。
- 捕捉、换宠、死亡和每 30 秒自动保存；F5 可手动保存。
- Esc 会冻结战斗、AI 与世界时间并显示操作帮助，再按一次继续。
- 剑诀、闪避、灵契投掷、捕捉成败、突破、书谱与对话均有 CC0 开源音效反馈，并支持并发播放与轻微音高变化。
- 2800×1800 青岚谷手绘整图、与画面地貌对齐的障碍碰撞、野怪补充和精英紫电狻猊。
- 按 M 打开完整青岚谷山河图；地图会安全冻结战斗，并按真实世界坐标显示玩家、青岚阵、导师、野生灵兽与首领试炼。

## 运行

最低需要 Godot 4.3；当前推荐使用官方稳定版 Godot 4.7.2：

1. 用 Godot 导入本目录下的 `project.godot`。
2. 点击运行项目，或在本目录执行 `godot --path .`。

仓库内已准备忽略版本控制的 Godot 4.7.2 便携运行时；当前版本已完成解析、逻辑、主场景集成与限帧运行验收。

在没有 Godot 的环境中可运行最小静态检查：

```powershell
pwsh -NoProfile -File .\tools\validate_project.ps1
```

运行 161 项核心逻辑检查：

```powershell
.\.tools\godot\Godot_v4.7.2-stable_win64_console.exe --headless --path . tests/test_runner.tscn
```

运行 69 项主场景端到端冒烟检查（使用隔离存档并自动清理）：

```powershell
.\.tools\godot\Godot_v4.7.2-stable_win64_console.exe --headless --path . tests/integration_runner.tscn
```

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | WASD |
| 剑诀 | 鼠标左键 |
| 主动御灵 | 鼠标右键 |
| 闪避 | Space |
| 契机中投掷灵契符 | Q |
| 切换出战灵兽 | R |
| 打开/关闭灵兽谱 | Tab |
| 打开/关闭青岚谷全图 | M（地图中也可按 Esc 关闭） |
| 与导师交谈 | E |
| 暂停/继续 | Esc |
| 手动保存 | F5 |

## 资产策略

当前整张青岚谷、修士、导师与五种灵兽均已接入统一画风的生成素材；CC0 音效与 UI 边框优先采用开源来源。素材升级持续按以下顺序执行：

1. 优先评估许可证允许商用与改作、风格一致的开源素材。
2. 开源素材无法覆盖的项目专属角色、灵兽和场景，使用 GPT Image 生成。
3. 所有外部素材登记来源、作者、许可证、修改记录和项目内路径。

详见 `docs/ASSET_POLICY.md`。
